Privacy Policy & Affiliate Disclosure

Last updated 10 September 2026

The Old Money Picks is a small independent publication about quiet luxury, written and run by one person. This page explains, in plain language, what happens to data when you visit, and how the links on this site earn money.

Affiliate disclosure. As an Amazon Associate, this site earns from qualifying purchases. Some links here are affiliate links, marked with a “Shop Now” button. If you buy through one, Amazon pays this site a small commission at no extra cost to you — the price you pay is the same either way. Products are chosen on their merits; being an affiliate does not change what gets recommended. Associates tag: oldmoneypicks-20.

What is collected

This site does not ask you to create an account, and it has no comment form, no newsletter sign-up, and no login. It does not collect names, email addresses, or payment details — there is nowhere on this site to enter them.

Analytics

The site uses Google Analytics 4 (measurement ID G-5MXY6JHJLC) to count visits and see which articles people read. Google sets cookies and receives information such as approximate location (city level), device type, browser, pages viewed, and which affiliate links were clicked. This is used only to decide what to write next.

Google’s own handling of that data is described in Google’s Privacy Policy. You can opt out for every site at once using the Google Analytics Opt-out Add-on, or by blocking cookies in your browser settings. Nothing on this site breaks if you do.

Affiliate links and Amazon

When you click an affiliate link, Amazon may set its own cookie so it can credit a purchase to this site. That cookie is Amazon’s, governed by Amazon’s Privacy Notice, and this site never sees what you bought, only that a commission was earned.

Pinterest

Articles and images from this site are shared on Pinterest (@theoldmoneypicks). Publishing is done through Pinterest’s official API using an access token held by the site owner. That token allows creating pins on this account only; it gives no access to any other Pinterest account, and no visitor data from this site is ever sent to Pinterest.

Hosting

The site is static HTML hosted on Vercel, which keeps standard server logs (including IP addresses) for security and abuse prevention. See Vercel’s Privacy Policy.

Children

This site is written for adults and is not directed at children under 13. No information is knowingly collected from them.

Your choices

  • Block or delete cookies in your browser at any time.
  • Use the Google Analytics opt-out linked above.
  • Write to the address below to ask what is held about you — the honest answer is almost certainly “nothing that identifies you”.

Changes

If this policy changes, the date at the top of the page changes with it. There is no mailing list to notify, by design.
